📁 1. Project File Structure

The project is split into three files. Each file has a single responsibility. Never put CSS in the JS file or HTML structure in the CSS file.

mendtrix/ ← root folder (deploy this whole folder)
index.html ← HTML structure only. No CSS. No logic.
CHEATSHEET.html ← this file
assets/
css/
style.css ← ALL visual styling (colors, fonts, layout, spacing)
js/
main.js ← ALL application logic (grades, attendance, exports)
Rule of thumb: If it's about how something looks → edit style.css. If it's about what something does → edit main.js. If it's about page structure or text labels → edit index.html.

🔤 4. Font Reference & How to Change

The system uses two fonts: DM Sans for all UI text, and DM Mono for numbers, grades, and code-style data.

FontUsed forCSS variable / property
DM SansAll body text, labels, buttons, navigation, namesfont-family:'DM Sans',sans-serif on body
DM MonoAll grades, scores, percentages, dates, IDsfont-family:'DM Mono',monospace on number cells

How to change to a different Google Font

/* Step 1: In style.css, replace the @import line at the very top */ @import url('https://fonts.googleapis.com/css2?family=YOUR+FONT:wght@400;500;600&display=swap'); /* Step 2: Update the body font-family */ body { font-family: 'Your Font', sans-serif; } /* Example: Switch to Poppins */ @import url('https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600&display=swap'); body { font-family: 'Poppins', sans-serif; }
When offline (no internet), Google Fonts will not load. The browser falls back to sans-serif system font. To work fully offline, download the font files and use @font-face instead.

🗄️ 5. Data Structure — How Data is Stored

All data lives in the APP object in main.js. It is automatically saved to localStorage and exported to .json files. Understanding this helps when you need to change what gets saved or exported.

➕ 8. How to Add a New Page or Module

Follow these 4 steps every time you want to add a new main page.

Step 1 — Add the page container in index.html

<!-- Add inside <div id="pagesContainer"> --> <div class="page" id="page-mypage"> <div class="pi" id="myPageContent"> <div class="ws"><h2>Loading...</h2></div> </div> </div>

Step 2 — Add it to the navigation in buildNav() in main.js

// Inside buildNav(), add to the items array: { id: 'mypage', icon: '📋', label: 'My New Page' }

Step 3 — Create a render function in main.js

function renderMyPage() { const el = document.getElementById('myPageContent'); if (!hasClass()) { el.innerHTML = '<div class="ws"><h2>Select a class first</h2></div>'; return; } el.innerHTML = `<div class="card">Your content here</div>`; }

Step 4 — Hook it up in showPage() in main.js

// Inside showPage(), add: if (n === 'mypage') renderMyPage();

🚀 9. Deployment Guide

Option A — Vercel (recommended for online access)

  1. Push the mendtrix/ folder to a GitHub repository
  2. Go to vercel.com → New Project → Import GitHub repo
  3. Vercel auto-detects it as a static site
  4. Deploy — done. Teachers get a URL like mendtrix.vercel.app
  5. Every git push auto-deploys the update
Free tier supports unlimited users. No server needed.

Option B — Direct HTML file (offline use)

  1. Copy the entire mendtrix/ folder to the teacher's computer
  2. Teacher double-clicks index.html to open in any browser
  3. Works 100% offline — no internet needed
  4. To update: replace the folder with the new version
When opening as a local file, some browsers may block font loading (CORS). Use Chrome or Edge for best results.

👩‍🏫 11. Teacher Workflow Guide (Data Safety)

Share this section with teachers so they understand how to keep their data safe.

Storage TypeWhereSurvives browser close?Survives clearing history?Works on other computers?
Auto-save (localStorage)Inside the browser on that specific computer✓ Yes✗ Lost✗ No
Exported .json fileTeacher's Downloads folder / USB / Google Drive✓ Yes✓ Yes✓ Yes

Recommended daily habit for teachers

  1. Start of session: Open the app → Click Load File → Select their latest .json file
  2. During session: Enter grades normally — app auto-saves every keystroke to the browser
  3. Every 15 minutes: App automatically downloads an AutoSave_... file — keep this in Google Drive
  4. End of session: Go to Setup tab → Click Save & Export File → Save it to a named folder or USB
  5. Never do: Clear browser history / use incognito mode / switch browsers without exporting first
